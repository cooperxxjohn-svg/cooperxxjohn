================================================================================
USAGE EXAMPLE
================================================================================

Python:
```python
from backend.drywall_calculator import DrywallCalculator

calc = DrywallCalculator(labor_rate=65.0)

room = {
    "name": "Bedroom",
    "length": 12.0,
    "width": 15.0,
    "height": 8.0,
    "openings": [{"width": 3.0, "height": 7.0, "type": "door"}],
    "inside_corners": 4,
    "has_ceiling": True
}

estimate = calc.estimate_project(room)

print(f"Total: ${estimate.costs.total:,.2f}")
print(f"Sheets: {estimate.materials.total_sheets}")
print(f"Labor: {estimate.labor.total:.1f} hours")
```

Output:
```
Total: $2,948.67
Sheets: 16
Labor: 25.1 hours
```

================================================================================
KEY DIFFERENCES: DRYWALL vs. PAINTING
================================================================================

| Aspect              | Painting          | Drywall                    |
|---------------------|-------------------|----------------------------|
| Input               | Square footage    | Linear + Square footage    |
| Output              | Gallons           | Sheets + Linear materials  |
| Labor driver        | Surface area      | Finish level + Area        |
| Waste factor        | 10% (simple)      | 15-30% (complex)           |
| Phases              | 1 (apply)         | 3 (frame, hang, finish)    |
| Finish options      | Paint type        | 6 ASTM levels              |
| Calculation method  | area × coverage   | Multi-formula system       |
