# Painting Calculation Formulas

## Surface Area Calculations

### Walls
```
Total Wall Area = Perimeter × Height
Perimeter = 2 × (Length + Width)
Net Wall Area = Total Wall Area - Deductions (windows, doors)

Example:
Room: 20' × 15' × 9' ceiling height
Perimeter = 2 × (20 + 15) = 70 linear feet
Total Wall Area = 70 × 9 = 630 sqft
Deductions: 2 windows (15 sqft each) + 1 door (21 sqft) = 51 sqft
Net Wall Area = 630 - 51 = 579 sqft
```

### Ceilings
```
Ceiling Area = Length × Width

Example:
Room: 20' × 15'
Ceiling Area = 20 × 15 = 300 sqft
```

### Trim/Baseboard
```
Trim Linear Footage = Perimeter - Door Widths
Trim Area = Linear Footage × Trim Height

Example:
Perimeter = 70 ft
Door width = 3 ft
Trim Linear Footage = 70 - 3 = 67 ft
Trim Height = 6 inches = 0.5 ft
Trim Area = 67 × 0.5 = 33.5 sqft
```

### Doors
```
Door Area = Height × Width × 2 (both sides)
Standard door = 7' × 3' = 21 sqft per side = 42 sqft total

Frame/Trim = (2 × Height + Width) × Frame Width
Standard frame = (2 × 7 + 3) × 0.5 = 8.5 linear feet
```

### Windows
```
Window Area = Height × Width × 2 (if painting sash)
Standard window = 3' × 5' = 15 sqft

Window Trim = Perimeter × Trim Width
Window Perimeter = 2 × (Height + Width) = 2 × (3 + 5) = 16 ft
Trim Width = 4 inches = 0.33 ft
Trim Area = 16 × 0.33 = 5.3 sqft
```

## Paint Volume Calculations

### Coverage Rates (per gallon)
```
Smooth Drywall: 400 sqft/gallon
Textured Drywall: 350 sqft/gallon
Smooth Plaster: 400 sqft/gallon
Rough Plaster: 325 sqft/gallon
Wood (trim): 350 sqft/gallon
Metal: 500 sqft/gallon
Concrete/Masonry: 300 sqft/gallon
Previously Painted: 400 sqft/gallon
```

### Number of Coats
```
Primer: 1 coat (always, unless paint+primer combo)
Finish Paint: 2 coats (standard)
Dark-to-Light Color Change: 3 coats
Ceiling: 1-2 coats (usually 2 for new construction)
Trim: 2-3 coats (higher traffic = more coats)
```

### Paint Volume Formula
```
Gallons Needed = (Surface Area × Number of Coats) / Coverage Rate × Waste Factor

Waste Factor:
- Small rooms (<200 sqft): 1.15 (15% waste)
- Medium rooms (200-500 sqft): 1.10 (10% waste)
- Large rooms (>500 sqft): 1.08 (8% waste)

Example:
Wall Area = 579 sqft
Coats = 1 primer + 2 finish = 3 total
Coverage = 400 sqft/gallon
Waste = 1.10

Primer: (579 × 1) / 400 × 1.10 = 1.59 gallons → Round up to 2 gallons
Finish: (579 × 2) / 400 × 1.10 = 3.18 gallons → Round up to 4 gallons
```

## Labor Time Calculations

### Production Rates (sqft/hour)

**Walls:**
```
Smooth walls: 300 sqft/hour
Textured walls: 250 sqft/hour
Rough walls: 200 sqft/hour
Rolling large areas: 350 sqft/hour
Cutting in (edges): 150 linear feet/hour
```

**Ceilings:**
```
Smooth ceiling: 350 sqft/hour
Textured ceiling: 300 sqft/hour
High ceiling (>10'): 250 sqft/hour
```

**Trim/Detail:**
```
Baseboard: 200 sqft/hour
Crown molding: 150 sqft/hour
Window frames: 20 sqft/hour (detailed work)
Door frames: 30 sqft/hour
```

### Labor Hour Formula
```
Base Hours = Surface Area / Production Rate
Prep Time = Base Hours × 0.15 (15%)
Touch-up Time = Base Hours × 0.05 (5%)
Total Labor Hours = Base Hours + Prep Time + Touch-up Time

Example:
Wall Area = 579 sqft
Production Rate = 300 sqft/hr
Base Hours = 579 / 300 = 1.93 hours

Walls (2 coats):
Base: 1.93 × 2 = 3.86 hours
Prep: 3.86 × 0.15 = 0.58 hours
Touch-up: 3.86 × 0.05 = 0.19 hours
Total: 3.86 + 0.58 + 0.19 = 4.63 hours → Round to 5 hours
```

### Labor Rates (USA Market)

## Complete Room Example

**Room Specifications:**
- Dimensions: 20' L × 15' W × 9' H
- 2 windows (3' × 5' each)
- 1 door (3' × 7')
- Baseboard: 6" height
- Paint type: Premium (Sherwin-Williams)
- Surface: Smooth drywall

**Step 1: Calculate Surface Areas**
```
Walls:
  Perimeter = 2 × (20 + 15) = 70 ft
  Gross Area = 70 × 9 = 630 sqft
  Deductions = 2 windows (15 sqft each) + 1 door (21 sqft) = 51 sqft
  Net Wall Area = 630 - 51 = 579 sqft

Ceiling:
  Area = 20 × 15 = 300 sqft

Trim:
  Linear feet = 70 - 3 (door) = 67 ft
  Area = 67 × 0.5 = 33.5 sqft

Door:
  Area = 21 sqft × 2 sides = 42 sqft
```

**Step 2: Calculate Paint**
```
Walls (579 sqft):
  Primer: (579 × 1) / 400 × 1.10 = 1.59 → 2 gallons
  Finish: (579 × 2) / 400 × 1.10 = 3.18 → 4 gallons

Ceiling (300 sqft):
  Primer: (300 × 1) / 400 × 1.10 = 0.83 → 1 gallon
  Finish: (300 × 2) / 400 × 1.10 = 1.65 → 2 gallons

Trim (75.5 sqft total):
  Finish: (75.5 × 2) / 350 × 1.10 = 0.47 → 1 gallon
```

**Step 3: Calculate Labor**
```
Walls:
  Base: (579 / 300) × 2 coats = 3.86 hours
  Prep: 3.86 × 0.15 = 0.58 hours
  Total: 4.44 hours

Ceiling:
  Base: (300 / 350) × 2 coats = 1.71 hours
  Prep: 1.71 × 0.15 = 0.26 hours
  Total: 1.97 hours

Trim/Door:
  Base: (75.5 / 200) × 2 coats = 0.76 hours
  Prep: 0.76 × 0.15 = 0.11 hours
  Total: 0.87 hours

Grand Total Labor: 4.44 + 1.97 + 0.87 = 7.28 → 8 hours
```

**Step 4: Calculate Costs**
```
Materials:
  Primer: 3 gallons × $40 = $120
  Finish (walls/ceiling): 6 gallons × $55 = $330
  Finish (trim): 1 gallon × $55 = $55
  Sundries: 879 sqft × $0.095 = $84
  Total Materials: $589

Labor:
  8 hours × $50/hour = $400

Total Cost: $589 + $400 = $989
Selling Price: $989 × 1.30 (30% margin) = $1,286
```
