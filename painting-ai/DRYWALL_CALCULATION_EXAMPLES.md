## Example 1: Simple Residential Room

### Room Specifications:
- **Dimensions:** 12' × 14' room
- **Ceiling Height:** 8 feet
- **Openings:** 1 door (3' × 7'), 2 windows (3' × 4' each)
- **Complexity:** Simple (standard rectangular room)
- **Location:** Atlanta, GA
- **Finish Level:** Level 4 (standard residential)

### Step 1: Calculate Wall Area
```
Wall Area = 2 × (Length + Width) × Height
Wall Area = 2 × (12 + 14) × 8
Wall Area = 2 × 26 × 8
Wall Area = 416 sqft
```

### Step 2: Calculate Ceiling Area
```
Ceiling Area = Length × Width
Ceiling Area = 12 × 14
Ceiling Area = 168 sqft
```

### Step 3: Subtract Openings
```
Door = 3 × 7 = 21 sqft
Windows = 2 × (3 × 4) = 24 sqft
Total Openings = 21 + 24 = 45 sqft
```

### Step 4: Calculate Net Area
```
Net Area = Wall Area + Ceiling Area - Openings
Net Area = 416 + 168 - 45
Net Area = 539 sqft
```

### Step 5: Add Waste Factor (10% for simple room)
```
Total Area = Net Area × (1 + Waste Factor)
Total Area = 539 × 1.10
Total Area = 593 sqft
```

### Step 6: Calculate Sheets Needed (using 4×8 sheets)
```
Sheets = ⌈Total Area ÷ Sheet Size⌉
Sheets = ⌈593 ÷ 32⌉
Sheets = ⌈18.5⌉
Sheets = 19 sheets (4×8, 1/2" regular drywall)
```

### Step 7: Calculate Joint Compound (Level 4)
```
Joint Compound = Total Area × 0.075 lbs/sqft
Joint Compound = 593 × 0.075
Joint Compound = 44.5 lbs

Or in buckets:
Buckets = Total Area ÷ 275 (4.5-gal buckets)
Buckets = 593 ÷ 275
Buckets = 2.2 ≈ 3 buckets (4.5-gallon)
```

### Step 8: Calculate Tape
```
Linear Feet = Sheets × Perimeter of Sheet
Perimeter of 4×8 = 2(4 + 8) = 24 feet
Linear Feet = 19 × 24 = 456 feet

Rolls needed (250ft per roll):
Rolls = ⌈456 ÷ 250⌉ = 2 rolls
```

### Step 9: Calculate Screws
```
Screws = Sheets × 32 (per 4×8 sheet)
Screws = 19 × 32
Screws = 608 screws

Pounds needed (230 screws/lb):
Pounds = ⌈608 ÷ 230⌉ = 3 lbs
```

### Step 10: Calculate Corner Bead
```
Assume 4 outside corners, 8 feet each:
Corner Bead = 4 × 8 = 32 linear feet
Pieces = 4 (8-foot pieces)
```

### Step 11: Calculate Labor Cost (Atlanta, GA)
```
Regional Multiplier for Atlanta = 0.85
Base Cost per SqFt (Level 4) = $2.25 (mid-range)

Labor Cost = Total Area × Cost/SqFt × Regional Multiplier
Labor Cost = 593 × $2.25 × 0.85
Labor Cost = $1,134

Labor Hours = Total Area × 0.065 (Level 4 hrs/sqft)
Labor Hours = 593 × 0.065
Labor Hours = 38.5 hours
```

### Step 12: Calculate Material Costs
```
Drywall (USG Sheetrock 1/2" 4×8): 19 × $12.50 = $237.50
Joint Compound (3 buckets @ $18): 3 × $18 = $54.00
Tape (2 rolls @ $6.50): 2 × $6.50 = $13.00
Screws (3 lbs @ $6.50): 3 × $6.50 = $19.50
Corner Bead (4 @ $2.25): 4 × $2.25 = $9.00
Primer (2 gal @ $22): 2 × $22 = $44.00

Total Materials = $377.00
```

### Step 13: Calculate Total Project Cost
```
Materials: $377.00
Labor: $1,134.00
Subtotal: $1,511.00

Add Overhead (35%) and Profit (20%):
Total Markup = $1,511 × 0.55 = $831
Final Project Cost = $1,511 + $831 = $2,342

Or ~$3.95/sqft installed (593 sqft)
```

## Example 2: Complex Living Room with Cathedral Ceiling

### Room Specifications:
- **Dimensions:** 20' × 16' room
- **Ceiling:** Cathedral, peak at 14 feet, walls at 8 feet
- **Openings:** 2 doors, 4 windows, fireplace opening
- **Complexity:** High (cathedral ceiling, multiple openings)
- **Location:** Seattle, WA
- **Finish Level:** Level 5 (high-end finish)

### Step 1: Calculate Wall Area (standard height)
```
Wall Area = 2 × (20 + 16) × 8 = 576 sqft
```

### Step 2: Calculate Cathedral Ceiling Area
```
For cathedral ceiling with peak:
- Two angled sections approximately 22' × 16'
- Ceiling Area ≈ 22 × 16 = 352 sqft

(More complex calculation for exact angle, but estimating)
```

### Step 3: Calculate Gable Wall Area
```
Two gable ends: triangle height ~6' (14' - 8')
Each gable = 0.5 × 16' × 6' = 48 sqft
Total gables = 2 × 48 = 96 sqft
```

### Step 4: Subtract Openings
```
Doors (2): 2 × 21 = 42 sqft
Windows (4): 4 × 15 = 60 sqft
Fireplace: ~30 sqft
Total Openings = 132 sqft
```

### Step 5: Calculate Net Area
```
Net Area = 576 + 352 + 96 - 132
Net Area = 892 sqft
```

### Step 6: Add Waste Factor (20% for complex cathedral)
```
Total Area = 892 × 1.20
Total Area = 1,070 sqft
```

### Step 7: Calculate Sheets (mix of sizes)
```
Use 4×12 sheets for efficiency:
Sheets = ⌈1,070 ÷ 48⌉ = 23 sheets (4×12)

Plus extra 4×8 for gables and cuts: +5 sheets
Total: 23 (4×12) + 5 (4×8) sheets
```

### Step 8: Calculate Materials for Level 5 Finish
```
Joint Compound (Level 5 = 0.095 lbs/sqft):
= 1,070 × 0.095 = 102 lbs

Buckets = 1,070 ÷ 200 (Level 5 uses more) = 5.4 ≈ 6 buckets

Plus skim coat compound: +2 buckets
Total: 8 buckets joint compound
```

### Step 9: Calculate Labor (Seattle, WA)
```
Regional Multiplier for Seattle = 1.50
Ceiling Height Multiplier (14' peak) = 1.40
Complexity Multiplier (high) = 1.35

Base Cost Level 5 = $3.50/sqft

Labor Cost = 1,070 × $3.50 × 1.50 × 1.40 × 1.35
Labor Cost = 1,070 × $9.95
Labor Cost = $10,647

Labor Hours = 1,070 × 0.095 (Level 5)
Labor Hours = 102 hours (×1.4 for height) = 143 hours
```

### Step 10: Calculate Material Costs
```
Drywall 4×12 (23 @ $16): $368
Drywall 4×8 (5 @ $12.50): $63
Joint Compound (8 @ $20): $160
Tape (4 rolls @ $11): $44
Screws (5 lbs @ $30): $150
Corner Bead: $80
Primer (3 gal): $66

Total Materials = $931
```

### Step 11: Total Project Cost
```
Materials: $931
Labor: $10,647
Subtotal: $11,578

Overhead (40%) + Profit (20%):
Markup = $11,578 × 0.60 = $6,947

Final Cost = $11,578 + $6,947 = $18,525

Or ~$17.31/sqft installed (1,070 sqft)
```

## Example 3: Commercial Office (Metal Framing)

### Project Specifications:
- **Space:** 2,000 sqft office tenant improvement
- **Ceiling Height:** 9 feet
- **Framing:** 25-gauge metal studs, 24" OC
- **Drywall:** 5/8" Type X (fire-rated)
- **Finish Level:** Level 4
- **Location:** New York, NY
- **Type:** Commercial tenant improvement

### Step 1: Calculate Total Wall Area
```
Perimeter: 200 linear feet (estimated)
Wall Area = 200 × 9 = 1,800 sqft
Ceiling Area = 2,000 sqft

Total Area = 1,800 + 2,000 = 3,800 sqft
```

### Step 2: Add Commercial Waste (15%)
```
Total with Waste = 3,800 × 1.15
Total = 4,370 sqft
```

### Step 3: Calculate Sheets (5/8" Type X, 4×12)
```
Sheets = ⌈4,370 ÷ 48⌉
Sheets = 91 sheets (4×12, 5/8" Type X)
```

### Step 4: Calculate Metal Framing
```
Linear Feet of Wall: 200 feet
Studs needed (24" OC = 0.5/LF): 200 × 0.5 = 100 studs
Add corners/openings: +20 studs
Total: 120 studs (9' length)

Track (top and bottom): 200 × 2 = 400 linear feet
```

### Step 5: Calculate Labor (New York)
```
Regional Multiplier for NYC = 1.70
Project Type Multiplier (Commercial TI) = 1.25
Ceiling Height (9') = 1.10

Base Commercial Cost = $3.50/sqft

Labor = 4,370 × $3.50 × 1.70 × 1.25 × 1.10
Labor = 4,370 × $8.24
Labor = $36,009
```

### Step 6: Material Costs
```
Drywall Type X 5/8" (91 @ $23): $2,093
Metal Studs (120 @ $8): $960
Metal Track (400 LF @ $1.50): $600
Joint Compound (16 buckets @ $20): $320
Tape (8 rolls @ $11): $88
Screws - fine thread (20 lbs @ $32): $640
Corner Bead: $200
Primer (12 gal @ $22): $264

Total Materials = $5,165
```

### Step 7: Total Project Cost
```
Materials: $5,165
Labor: $36,009
Subtotal: $41,174

Commercial Overhead (45%) + Profit (25%):
Markup = $41,174 × 0.70 = $28,822

Final Cost = $41,174 + $28,822 = $69,996

Or ~$16.02/sqft installed (4,370 sqft)
Or $35/sqft of office space (2,000 sqft)
```

## Formula Reference Card

### Area Calculations:
```
Wall Area = 2 × (Length + Width) × Height
Ceiling Area = Length × Width
Opening Area = Width × Height
Net Area = Wall + Ceiling - Openings
Total Area = Net Area × (1 + Waste%)
```

### Material Quantities:
```
Sheets Needed = ⌈Total Area ÷ Sheet SqFt⌉
Joint Compound (lbs) = Total Area × lbs/sqft (by level)
Joint Compound (buckets) = Total Area ÷ 275
Tape (LF) = Sheets × Sheet Perimeter
Screws = Sheets × 32 (for 4×8) or × 40 (for 4×12)
Corner Bead (LF) = Number of corners × 8
```

### Framing:
```
Studs (16" OC) = ⌈(Wall Length × 12) ÷ 16⌉ + 1 + extras
Studs (24" OC) = ⌈(Wall Length × 12) ÷ 24⌉ + 1 + extras
Studs per LF (16" OC) = 0.75
Studs per LF (24" OC) = 0.5
```

### Labor Costs:
```
Base Labor = Total Area × Cost/SqFt
Regional Adjusted = Base × Regional Multiplier
With Height = Regional × Height Factor
With Complexity = Height Adjusted × Complexity Factor
Final Labor = Complexity × Project Type Factor
```

### Total Project:
```
Subtotal = Materials + Labor
Overhead = Subtotal × Overhead%
Profit = (Subtotal + Overhead) × Profit%
Final Cost = Subtotal + Overhead + Profit

Or using markup:
Final Cost = Subtotal × (1 + Markup%)
```
